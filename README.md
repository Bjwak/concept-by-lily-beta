# Concept by Lily

Proyecto unificado para GitHub Pages.

## Estructura
- `index.html`: página principal.
- `mujer/`: catálogo femenino actual.
- `cosmeticos/`: catálogo de cosméticos y maquillaje actual.
- `hombre/`: página provisional con el banner masculino recibido. La tienda masculina aún no tiene catálogo de productos.
- `imagenes/`: imágenes usadas por la página principal.
- `css/` y `js/`: estilos y comportamiento de la página principal.

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a la raíz del repositorio `concept-by-lily-beta`.
2. En GitHub abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y espera a que GitHub Pages publique el sitio.

## Importante
- Conserva esta estructura de carpetas. Los catálogos usan imágenes locales mediante rutas relativas.
- Los catálogos femenino y cosméticos se han copiado desde los ZIP proporcionados, sin reescribir su lógica interna.
- La sección masculina es provisional porque el ZIP recibido contiene únicamente el banner y un bosquejo, no productos masculinos.
- Antes de reemplazar el repositorio de producción, prueba las tres secciones, los pedidos y la visualización en móvil en el repositorio beta.
